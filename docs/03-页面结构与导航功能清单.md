# 第三部分：页面结构、导航设计与功能清单

## 1. 导航设计（按你的建议采用五项）

```
导航栏：首页 | 文章 | 分类 | 项目 | 关于
页脚：  归档 · 搜索 · 标签 · 友链 · 更新日志 · 隐私与版权 · RSS
侧边栏：头像/简介 · 搜索框 · 彩色分类 · 标签云 · 近期归档 · 社交图标
```

实现位置：导航在 `config/_default/menu.toml` + 各页面 front matter；页脚在
`layouts/_partials/footer/custom.html`；侧边栏组件在 `params.toml [widgets]`。

## 3. 功能价值/成本评估（防堆砌原则）

| 功能 | 价值 | 成本/维护负担 | 结论 |
|---|---|---|---|
| 全文搜索 | 高：知识库检索刚需 | 零（主题内置，构建时生成索引） | ✅ 必备 |
| 目录 + 进度条 + 返回顶部 | 高：长文阅读体验 | 零/极低 | ✅ 必备 |
| 代码复制 | 高：技术博客刚需 | 零（主题内置） | ✅ 必备 |
| Mermaid / LaTeX | 中高：技术表达 | 按需加载，不用不付出代价 | ✅ 保留 |
| 评论 | 中：互动与反馈 | 低（giscus 免费，依托 GitHub 登录，垃圾评论极少） | 🔶 推荐启用 |
| 统计 | 中：了解读者 | 低（一段 `<script>`）；注意隐私披露 | 🔶 推荐启用 |
| 邮件订阅 | 低→中：早期读者少 | 中（第三方服务管理） | ⏸ 可选，见 13 |
| 站内搜索替换为 Algolia | 低：当前索引方案已够快 | 中（外部依赖+配额） | ⏸ 不推荐 |
| 文章浏览量显示 | 低 | 需外部服务/函数 | ⏸ 可选 |
