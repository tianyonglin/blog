# 第四部分：视觉设计规范

> 全部已在 `assets/scss/custom.scss` + 主题变量中落地，本文是规范说明与修改入口。

## 1. 品牌元素

| 元素 | 当前值 | 修改位置 |
|---|---|---|
| 站名（中英） | 拾贝集 · The Beachcomber | `config/_default/languages.toml` |
| 标语 | 在海边拾贝，把生活的碎片收集起来 | 同上 |
| Logo / 头像 | 贝壳插画 `static/img/avatar.png` | 换图即可（建议正方形 ≥ 512px） |
| Favicon | 同头像 | `params.toml` `favicon` |
| 表情符号 | 🐚（侧边栏头像角标） | `params.toml` `sidebar.emoji` |

## 2. 色彩体系（专业蓝，全量实测见文档 14）

| 角色 | 浅色模式 | 深色模式 | 用途 |
|---|---|---|---|
| 页面背景 | `#F8FAFC` | `#0B1220` | body |
| 卡片背景 | `#FFFFFF` | `#111827` | 文章卡片/侧栏 |
| 正文文字 | `#1E293B` | `#E5E7EB` | 标题、正文 |
| 次要文字 | `#475569` | `#AAB6C5` | 摘要、元信息 |
| 主色（品牌蓝） | `#2563EB` | `#60A5FA` | 链接、按钮、选中态、进度条 |
| 主色悬停 | `#1D4ED8` | `#93C5FD` | hover/active |
| 分隔线 | `#E2E8F0` | `#334155` | 边框、分隔 |
| 代码背景 | `#F1F5F9` | `#0F172A` | 行内代码、代码块 |
| 分类徽章 | 技术 `#2563EB` / 生活 `#0F766E` / 阅读 `#7C3AED` | 同 | `content/categories/*/_index.md` 的 `style` |

全站所有前景/背景组合均通过 WCAG AA 对比度检测（正文 ≥ 7:1，链接/按钮 ≥ 4.5:1）；
渐变仅两处且为同色系（站名、进度条）。完整变量表、检测方法与复跑脚本见 **`docs/14-配色与阅读体验规范.md`**。

## 3. 字体

- 正文：系统字体栈 `-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei"…`（零下载成本，跨 Win/macOS/Android/iOS 均原生渲染）；
- 代码：`ui-monospace, SFMono-Regular, Menlo, Consolas`；
- **不引入 Web 字体**：省去数百 KB 下载与 FOUT 闪烁（性能决策，见文档 09）。

## 4. 排版度量（主题默认，已适配中文）

| 项 | 值 |
|---|---|
| 正文宽度 | 内容列约 700px，页面最大约 1280px（双栏） |
| 行高 | 1.8（中文长文阅读友好） |
| 段落间距 | 1.4em |
| H1 | 文章页标题，每页唯一 |
| H2 | 章节（自动进目录、带锚点） |
| H3 | 小节 |
| 卡片 | 圆角 10px、柔和阴影、悬停上浮 3px |
| 按钮/标签 | 圆角胶囊 999px、1px 描边 |

## 5. 深浅色模式

三态：**跟随系统（默认）→ 手动浅色 → 手动深色**，切换按钮在导航栏，选择存入 `localStorage`，无闪烁（头部内联脚本提前设色）。

## 6. 交互与阅读增强

| 功能 | 实现 |
|---|---|
| 文章目录 + 标题锚点 | 主题内置（右侧栏，滚动高亮） |
| 阅读进度条 | `footer/custom.html` + `custom.scss`（顶部 3px 渐变） |
| 返回顶部 | 同上（滚动超 600px 出现） |
| 图片懒加载 + 点击放大 | 主题内置（PhotoSwipe，带图注） |
| 代码高亮 + 一键复制 | 主题内置 |
| 分享按钮 | 文章页底部：X / Telegram / 复制链接 |
| 社交预览 | OG + Twitter Card（主题输出，见 07） |

## 7. 响应式

断点由主题控制（移动端单列、侧栏收起为顶栏菜单、卡片全宽、表格横向滚动）。
验收方式：浏览器开发者工具切换 iPhone / iPad / 1080p 三档 + 真机访问（见 12 检查表）。

## 8. 无障碍（a11y）基线

- 全站键盘可达（导航/按钮均为标准元素，`:focus-visible` 描边）；
- 文字对比度：正文黑/奶油底远超 WCAG AA；深色模式同理；
- 图片必须写 ALT：`![替代文本](图片)` —— **写作规范强制项**（见文档 10）；
- 语义化：`<article> <nav> <time> <figure>`；标题层级不跳级；
- 动画克制：仅卡片悬停与进度条，无自动播放/弹窗（符合 `prefers-reduced-motion` 场景）。
