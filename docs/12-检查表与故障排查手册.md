## 3. 常见故障排查手册

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 域名打不开 | DNS 未生效 | 等（最长 48h）；`nslookup 域名` 看记录是否正确；清浏览器缓存 |
| 证书一直签发失败 | DNS 未指向平台 / GitHub 未绑域名 | 核对文档 06 记录；GitHub 侧重新保存 Custom domain |
| GitHub Pages 显示 404 | Source 选错（选了 branch 却没内容） | Source 应为 **GitHub Actions** |
| Actions 构建失败：hugo 报错 | 内容语法错误（front matter 缩进、日期格式） | 看日志行号，定位对应 .md；日期必须 `YYYY-MM-DD` |
| Actions 失败：找不到主题 | 主题目录没推上去 | 确认 `themes/hugo-theme-stack/` 在仓库里（不要放 `.gitignore`） |
| 样式丢失/错乱 | `baseURL` 末尾缺 `/` 或路径错误 | 修正后重新推送 |
| 搜索无结果 | 搜索页缺 `outputs: [html, json]` | 对照仓库 `content/page/search/index.md` |
| 文章图片 404 | 图片不在文章文件夹 / 文件名大小写不符 | Linux 构建机区分大小写，统一小写 |
| 中文分类页打不开 | 直接输中文被转义 | 用页面上的链接进入；已配 `slug` 时用 slug 访问 |
| 更新后线上没变 | 浏览器缓存 / CDN 缓存 | 强刷；CF 用户 Purge |
| giscus 报错 | repoID/categoryID 错或仓库非 Public | 到 <https://giscus.app/zh-CN> 重新生成 |
| 评论/统计加载慢 | 第三方服务网络 | 属正常现象，已懒加载，不影响正文 |
| 想回滚到旧版本 | 误改配置/内容 | `git log` 找到好的提交 → `git revert` 或网页上恢复该文件历史版本 |

## 4. 故障处理总原则

1. 先看 **CI 日志**（构建问题）→ 再看 **DNS**（解析问题）→ 再看 **浏览器缓存**（显示问题）；
2. 每次只改一处，验证后再改下一处；
3. 改配置前先 `git diff` 看自己改了什么；
4. 任何破坏性操作前，先按文档 08 做一次备份。
