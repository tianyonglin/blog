# 配色系统与阅读体验规范（专业蓝 · 已实测落地）

> 状态：**已实施**。全部颜色已写入 `assets/scss/custom.scss` 并通过构建渲染。
> 对比度数据由 `scripts/contrast_check.py` 按 WCAG 2.1 公式实测计算，可随时复跑复核。

## 1. 设计原则（落地版）

1. **阅读优先**：正文区永远是「低刺激底 + 高对比字」，彩色只出现在链接、徽章、按钮等信息锚点上；
2. **品牌克制**：品牌蓝只用于可交互元素与重点标识，不大面积铺底；全站仅两处同色系渐变（站名、进度条）；
3. **状态不只靠颜色**：提示框带图标+标题词、代码块带语言标签与行号、禁用态降低不透明度并禁用指针；
4. **双模式一致性**：浅色/深色各持一套完整令牌，深色模式品牌蓝提亮（#2563EB→#60A5FA）以维持对比；
5. **零动画负担**：全站动效只有卡片悬停上浮与进度条，无弹窗、无自动播放。

## 3. 设计令牌代码

完整实现即仓库 `assets/scss/custom.scss`（头部 `:root` 与 `[data-scheme="dark"]` 两段）。
核心结构：

```css
:root {
    --body-background: #F8FAFC;
    --accent-color: #2563EB;
    --accent-color-darker: #1D4ED8;
    --accent-color-text: #FFFFFF;
    --card-background: #FFFFFF;
    --card-text-color-main: #1E293B;
    --card-text-color-secondary: #475569;
    --card-separator-color: #E2E8F0;
    --code-background-color: #F1F5F9;
    --code-text-color: #475569;
    --alert-note-color: #2563EB;  --alert-note-background: #EFF6FF;
    /* …其余令牌见源文件… */

    &[data-scheme="dark"] {
        --body-background: #0B1220;
        --accent-color: #60A5FA;
        --card-background: #111827;
        --card-text-color-main: #E5E7EB;
        /* …深色令牌见源文件… */
    }
}
::selection { background: var(--accent-color); color: var(--accent-color-text); }
a:focus-visible, button:focus-visible { outline: 2px solid var(--accent-color); outline-offset: 2px; }
```

换肤方法：只改这一处。未来若要换品牌色，替换 `--accent*` 三件套并重跑
`python3 scripts/contrast_check.py` 确认链接/按钮组合仍 ≥ 4.5:1。

## 5. 对比度检测：方法与结果

**方法**：WCAG 2.1 相对亮度公式
$L = 0.2126R + 0.7152G + 0.0722B$（sRGB 分量线性化），对比度 $= (L_1+0.05)/(L_2+0.05)$。
脚本 `scripts/contrast_check.py` 对**实际使用组合**逐一计算（含 alpha 混合后的真实底色）。

**结果摘要**（完整输出即复跑脚本所见）：

| 组别 | 范围 | 结论 |
|---|---|---|
| 浅色正文/次要文字 × 卡片/页面底 | 7.24 ~ 14.63:1 | 全部 ≥ AA（正文 ≥ 7:1 达 AAA 级） |
| 品牌蓝链接 × 卡片/页面底 | 4.94 ~ 5.17:1 | ≥ 4.5:1 ✓ |
| 按钮文字 × 品牌蓝（浅/深） | 5.17 / 7.36:1 | ✓ |
| 深色正文/次要/链接 | 6.98 ~ 15.12:1 | ✓ |
| 行内代码（修正后） | 6.92:1 | ✓（修正前 3.61:1 ✗） |
| 分类徽章 × 白字 | 5.17 ~ 5.70:1 | ✓（旧色 2.79~3.86 ✗ 已替换） |
| 提示框标题 × 底色（浅/深） | 4.75 ~ 8.38:1 | ✓ |
| 大字号标题（≥24px） | 同正文组合 | 远超 3:1 大字标准 ✓ |

**复跑验证**：

```bash
# 执行环境：任意装有 Python 3 的终端；目录：仓库根
python3 scripts/contrast_check.py
```

预期结果：输出与本文一致的对比度表，且全部为 PASS。

## 7. 长文阅读排版规范

| 项 | 值 | 理由 |
|---|---|---|
| 中文字体栈 | 系统栈：PingFang SC / Microsoft YaHei / Noto Sans SC | 零下载、全平台原生 |
| 英文/代码 | 系统无衬线 + `ui-monospace, Menlo, Consolas` | 与中文混排自然 |
| 正文字号 | 16px（移动端不缩小） | 低于 15px 长文易疲劳 |
| 标题 | H1 28~32px / H2 22px / H3 18px，逐级不跳级 | 层级即导航 |
| 行高 | 1.8（主题默认，中文最优区间 1.7~1.9） | 行间呼吸感 |
| 正文宽度 | 内容列约 700px（每行 35~40 个汉字） | 超过 45 字/行回行困难 |
| 段落间距 | 1.4em，段内不额外空行 | 靠间距而非缩进分段 |
| 列表/引用 | 引用带 3px 品牌色左边线 + 浅底 | 引用块可读且可扫读 |
| 章节锚点 | H2/H3 自动锚点 + 右侧目录滚动高亮 | 长文定位 |
