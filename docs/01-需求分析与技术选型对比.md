# 第一部分：需求分析与技术选型对比

## 1. 需求拆解

| 需求 | 技术含义 |
|---|---|
| 个人品牌 + 技术文章 + 知识库 + 项目展示 | 内容以文章为主，需分类/标签/搜索/自定义页面 |
| 低成本、稳定、易维护 | 静态站点 + 免费托管优先；避免服务器运维 |
| 速度快 | 无数据库查询、CDN 分发、资源精简 |
| 安全 | 无后台、无数据库 → 攻击面最小化 |
| 全设备兼容 | 响应式主题 + 标准 HTML |
| 长期运营 | 内容存于 Git（纯文本 Markdown），不绑定任何平台，随时可迁移 |

**核心结论**：内容型个人博客的最优解是 **静态站点生成器（SSG）+ 免费静态托管 + Git 版本管理**。数据库型方案（WordPress）在本场景下成本与风险都更高。

## 2. 五种方案对比

| 维度 | Hugo | Hexo | Astro | WordPress | 纯 HTML 手写 |
|---|---|---|---|---|---|
| 运行依赖 | 单个可执行文件（Go） | Node.js + npm | Node.js + npm | PHP + MySQL 服务器 | 无 |
| 构建速度 | 毫秒~秒级（最快） | 秒级 | 秒级 | 不构建（运行时渲染） | 无 |
| 写作体验 | Markdown | Markdown | Markdown/MDX | 可视化后台 | 手写 HTML |
| 主题生态 | 丰富（中文社区活跃） | 非常丰富（中文圈最强） | 增长中，博客模板偏少 | 最大 | 无 |
| 托管成本 | 免费（Pages 类） | 免费（Pages 类） | 免费（Pages 类） | 服务器 ¥30~100+/月 | 免费 |
| 维护负担 | 极低 | 低（偶尔需处理 npm 依赖冲突） | 中（前端生态更新快） | 高（插件/安全/备份/升级） | 高（每篇手工写 HTML） |
| 安全性 | 高（纯静态） | 高（纯静态） | 高（纯静态） | 中（常见攻击目标，需防护） | 高 |
| 扩展上限 | 高（可加 Hugo 模块/自写模板） | 高（插件多） | 很高（可渐进引入交互组件） | 很高（但伴随运维） | 低 |
| 迁移成本 | 内容为 Markdown，随时可换工具 | 同左 | 同左 | 导出迁移较麻烦 | 高 |

## 3. 淘汰理由与最终选择

- **WordPress**：需要持续付费的服务器、系统/PHP/插件升级、防暴力破解与垃圾评论。个人静态内容用它是“高射炮打蚊子”，运维风险 > 收益。**淘汰**（除非未来需要多人协作编辑后台）。
- **纯 HTML**：v1 版已验证不可持续——每篇文章要复制整套页面结构，无分类/标签自动化。**淘汰**。
- **Hexo**：优秀且中文生态最好，但依赖 Node 环境，`npm install` 在不同机器上偶发依赖冲突；构建速度也慢于 Hugo。可选但不首选。
- **Astro**：现代、性能极佳，适合未来需要交互组件（如作品演示）时再引入。当前纯内容博客用它属于过度设计。
- **Hugo（✅ 选定）**：单文件安装、构建最快、无依赖地狱、Stack 主题开箱即得卡片式设计/搜索/评论接口/结构化数据友好。GitHub Actions 官方提供 Hugo 部署模板。

## 4. 托管平台对比（均免费、均含 HTTPS 与 CDN）

| 维度 | GitHub Pages | Cloudflare Pages |
|---|---|---|
| 构建方式 | GitHub Actions（仓库内工作流） | 平台内置构建 |
| 国内访问速度 | 一般 | 略好（节点更多，但也未在国内备案加速） |
| 自定义域名 | 支持，证书自动 | 支持，证书自动 |
| 附加能力 | — | 可无缝接 Workers、Web Analytics、重定向规则 |
| 适合 | 最简路径，内容即仓库 | 想要更强网络/后续接 API |

**本方案**：默认 **GitHub Pages**（零额外账号），文档 05/06 同时给出 Cloudflare Pages 完整步骤，二选一即可。

> 若主要读者在中国大陆且要求访问速度，可另行购买国内云服务器并做 ICP 备案（`.top` 为工信部可备案后缀）；托管流程见 13。
