# 第十三部分：可选功能与后续扩展路线

> 每项都给出价值、成本与建议，按需取用，避免堆砌。

## 1. 近期可启用（低成本高收益）

### 1.1 评论系统：giscus（推荐）
- 价值：读者反馈、纠错、互动；依托 GitHub 登录，垃圾评论极少。
- 成本：0 费用；需要你 5 分钟配置（步骤见 `README.md`「启用评论」）。
- 国内替代：Twikoo / Waline（可部署到 Vercel 免费档），`params.toml` 已预留配置；维护负担略高。

### 1.2 访问统计
| 方案 | 优点 | 注意 |
|---|---|---|
| Umami（umami.is 云版免费） | 轻量、无 Cookie、界面清爽 | 一段脚本填入 `head/custom.html` |
| Cloudflare Web Analytics | 若用 CF 托管，一键开启 | 需域名走 CF 代理或加 beacon 脚本 |
| Google Analytics 4 | 生态最全 | 脚本较重，注意隐私披露 |

### 1.3 可用性监测
UptimeRobot 免费档监测首页 + 一篇文章（文档 08 第 6 节）。

## 2. 中期扩展

### 2.1 多语言（中文主 + 英文辅）
Hugo 原生多语言：`languages.toml` 增加 `[en]`，英文文章存为 `index.en.md`，主题自动出语言切换。
成本：每篇多语言需双份维护——建议**只给代表作配英文版**，不追求全量。

### 2.2 系列文章 / 专栏
文章 front matter 加 `series: ["Hugo 实战"]`，文末手工维护系列导航；或用 Hugo taxonomy 自定义 `series` 字段自动生成聚合页。

### 2.3 邮件订阅
作品积累到 20+ 篇再考虑。选 Buttondown / Mailchimp 免费档，在页脚放订阅框。维护负担：中（每篇手动/自动推送）。

### 2.4 国内访问优化
- 前提：主要读者在大陆且速度是痛点；
- 路线：购买国内轻量应用服务器 → Nginx 托管同一份 `public/` → 完成 ICP 备案（`.top` 可备案）→ 可选接国内 CDN；
- 成本：服务器约 ¥50~100/年活动价 + 备案约 1~3 周流程；
- 注意：备案主体需实名，网站内容需合规；静态产物可直接复用本仓库构建结果。

## 3. 远期演进

| 方向 | 触发条件 | 说明 |
|---|---|---|
| 迁移 Astro | 需要交互式作品演示 | 内容仍是 Markdown，迁移成本主要在模板层 |
| 自建 Umami | 云版配额不够 | 一台小 VPS + Docker |
| 内容授权/转载管理 | 有机构来要转载 | 在隐私与版权页补充授权流程 |
| 作品集独立子域 | 项目多到 10+ | `works.sunmusic.top` 单独建站，导航互链 |

## 4. 明确不建议做的

| 不做 | 理由 |
|---|---|
| 首页塞满 Widget | 信息噪音，违背简洁定位 |
| 引入广告位 | 个人品牌博客收益极低、体验伤害大 |
| 频繁换主题 | 每次换主题都是一轮全站回归测试 |
| 为指标装一堆性能插件 | 本站基线已优，边际收益为零 |
| 追热点日更 | 质量 > 数量，见文档 11 运营节奏 |
