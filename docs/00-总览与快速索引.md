## 功能分级（必备 / 推荐 / 可选）

- **必备（已实现）**：首页、文章列表、文章详情（目录/阅读时间/更新时间/代码高亮/相关文章/上下篇）、分类、标签、归档、关于、搜索、404、RSS、隐私与版权、更新日志、深浅色、响应式、sitemap、robots、canonical、OG/Twitter Card、JSON-LD、阅读进度条、返回顶部、分享按钮
- **推荐（待你启用）**：评论（giscus）、访问统计（Umami/GA4）、Google Search Console、Bing Webmaster、UptimeRobot 监控
- **可选（见 13）**：多语言、邮件订阅、系列文章、代码演示嵌入、自建统计服务器
